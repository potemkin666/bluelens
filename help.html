Start here for startup steps, privacy expectations, troubleshooting, and the operator-visible defaults that shape launch behavior.

Startup

  1. Run node server.js from the repository root.
  2. Open http://localhost:8787.
  3. Choose an image to inspect locally, then explicitly run a launch action when you want provider links.
  4. Open the Doctor panel for a one-screen check of server, popup, storage, CDN, and upload-host reachability.

Privacy

  • Hashes, EXIF parsing, OCR, and comparison stay local in the browser.
  • Choosing an image stays local; launch actions upload to a temporary public host only after you trigger them.
  • Use Share safe to upload a clean re-encoded copy instead of the original file.

Troubleshooting

  • If upload or launch actions fail immediately, confirm the local server is running.
  • If dragging a remote image URL fails, the origin likely blocked browser fetches; save the file locally first.
  • Wait tabs reconnect automatically, but they still need the local server to stay reachable.
