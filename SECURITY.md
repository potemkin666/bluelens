# Security Policy

## Supported usage

BlueLens is intended to run locally. The bundled server listens on `127.0.0.1` by default.

## Reporting a vulnerability

Please report suspected security issues privately through GitHub security reporting or another private maintainer channel.

Include:

- affected file or feature
- reproduction steps
- impact
- any suggested mitigation

Please do not open a public issue for an unpatched security vulnerability.
