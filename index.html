BlueLens

Inspect images locally, extract context, and launch reverse-search providers.

Help
Local-first image triage

Inspect one image locally before you open external search tools.

BlueLens computes local hashes, parses metadata, runs OCR, compares a second image, and can open reverse-search pages after you explicitly create a public URL. It does not ingest search-engine results or prove provenance on its own.

Local file signals

Compute SHA-256, MD5, dHash, dimensions, and a clean-copy fingerprint set.

Metadata inspection

Extract EXIF/IPTC/XMP fields, camera/software tags, and GPS coordinates when present.

OCR text extraction

Run OCR locally, pull URLs, emails, @handles, and phone numbers, and open manual pivots from the extracted text.

Reverse-search launchpad

Create a public URL on demand, then open Lens, Bing, TinEye, Yandex, and Google result pages for manual review.

Near-duplicate compare

Compare two local images with dHash distance to spot likely matches and obvious differences.

Batch local triage

Generate per-file reports, cluster local files by dHash, and sort by simple triage signals.

Caseboard notes

Store local reports, pivots, notes, and thumbnails in browser storage for later review.

Clean-copy export

Re-encode a local copy to strip metadata before sharing or saving a sanitized artifact.
